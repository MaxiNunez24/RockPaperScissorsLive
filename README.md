# 🎮 Rock Paper Scissors Live

A real-time rock-paper-scissors game using webcam hand gesture recognition and emotion detection.

## Features

- 🤚 **Hand Gesture Recognition** - Play using real hand gestures (MediaPipe)
- 😊 **Emotion Detection** - Get encouraging messages based on your facial expressions
- 📱 **Fully Responsive** - Works on desktop and mobile devices
- 🎨 **Modern UI** - Glass-morphism design with smooth animations
- 🏆 **Score Tracking** - Keep track of wins and losses

## How to Play

1. Open `index.html` in a web browser
2. Allow camera access when prompted
3. Show your hand to the camera:
   - ✊ Fist = Rock
   - ✋ Open hand = Paper
   - ✌️ Two fingers = Scissors
4. The game will detect your gesture and play against the computer!

## Technologies Used

- HTML5 Canvas & Video
- MediaPipe Hands (Hand gesture recognition)
- Face-API.js (Emotion detection)
- CSS3 (Responsive design with glass-morphism effects)
- Vanilla JavaScript

## Live Demo

Simply open `index.html` in any modern web browser that supports camera access.
